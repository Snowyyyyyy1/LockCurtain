# 提案目录

这里放**尚未合入**的改动提案。每个子目录自包含，不引用 `Sources/` 的私有状态，
可以直接评审、单独编译、单独测试。

合入后请把对应目录删掉或移到 `proposals/archive/`，避免和主干代码漂移。

## 目录

| 目录 | 主题 | 状态 |
|---|---|---|
| `archive/screen-rebuild-debounce/` | 屏幕参数变化合并（debounce + 差异比对） | 已合入（有改动，见该目录 `MERGED.md`） |

## 提案约定

1. **不改 `Sources/` 里任何既有文件**，只提供新文件 + 集成步骤
2. 能被 `xcrun swiftc -typecheck` 独立通过
3. 带可运行的自测，且自测要能跑出结果
4. 集成步骤写成精确的 before/after，不写「大概这样」
5. 说明冲突点、回滚方式、验收标准
