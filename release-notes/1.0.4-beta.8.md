测试版：

- Windows 版也能让手机走网络连这台电脑了：设置 › 手机里打开「让手机走网络连这台电脑」，把显示的地址（旁边有「拷贝」）填到手机里。走网络能盖上幕布、开关保持唤醒；撤下只能靠蓝牙。
- Windows 版：手机隔很久再打开，连上快多了。电脑对认识的手机最多等 8 秒就重新连，不再干等 30 秒。
- Windows 版小了很多：安装包从约 144 MB 降到约 4 MB，更新包从约 76 MB 降到约 6 MB。现在用的是 Windows 自带的 .NET Framework 4.8，不再自己带一份运行时。
- 修了几个小毛病：没有蓝牙的电脑打开设置 › 手机时会不停地重试蓝牙；配对窗口在高缩放的屏幕上只有一半大，还会被设置窗口挡在后面。
