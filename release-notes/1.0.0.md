LockCurtain 第一个公开版本，Mac 和 Windows 都有。

- 离开模式：遮罩盖住屏幕，agent 在底下照常干活；真人一碰键鼠，先锁屏再撤遮罩
- 遮罩对截屏、录屏透明，后台自动化看到的还是真实桌面
- [mac] 锁屏时也盖一层遮罩
- 遮罩的图案、背景、文字都能换（背景：壁纸 / 模糊壁纸 / 纯黑 / 星空 / 远山 / 碳纤维）
- 规则：满足条件时自动进入离开模式
- [mac] 菜单栏面板：谁在阻止睡眠、过去 24 小时睡了多久、保持唤醒
- [win] 托盘面板：谁在阻止睡眠、过去 24 小时的睡眠和唤醒、保持唤醒
- 自动更新：每天检查一次，遮罩显示时不提示、不重启
